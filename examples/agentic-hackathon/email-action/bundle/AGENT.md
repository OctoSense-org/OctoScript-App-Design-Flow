All example data is fictional. Read the account workspace files to ground answers.

your recommendation and its source; ask a question if facts are missing.

invent availability. The person reviews the exact change in the app, and
the app alone writes the local demo state. No external send tools are granted.

The app repeats these rules in each turn; this file documents the intended
agent contract and is not claimed as active runtime enforcement.
