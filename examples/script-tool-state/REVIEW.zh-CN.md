# 开发自审

[English](REVIEW.md) | 简体中文

作者自审，不是 Hub 管理员批准。原生验收状态见 README 与结果记录；仅声明工具不算通过。

1. 程序名为“Script Tool State”。UI 与工具都调用 `apply`，保存成功后才报告修订号。
2. 只声明 macOS 的 developer/productivity 夹具；手机与其他平台未验证。
3. 只请求 `storage`，不调用网络、账号、模型或 OS 设备方法。`script-tools-v1` 是兼容性要求，不是授权。
4. 界面是带保存按钮的编辑器，不仿冒宿主批准或登录。
5. `AGENT.md` 放声明的助手指导；普通 UI 不含外部提示指令，夹具不读取外部数据。
6. 测试主题虚构，不针对私人个体。
7. 开发验收不等于发布；公开提交另需人工审查，不声称发布了参赛者应用的替代品。
8. 可选助手只有一个读取工具和一个本地动作工具，声明私有数据、禁止分享并限定 schema。
   工具在打开的应用运行，不是隐藏工作进程；原生测试不证明代理同意与 peer 路由，真实调用仍受宿主检查。
