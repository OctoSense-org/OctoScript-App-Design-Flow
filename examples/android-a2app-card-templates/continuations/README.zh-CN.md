## 冻结并导入源码

使用独立且不可覆盖的目录：`deepseek/turn-N/` 和 `minimax/turn-N/`。
未完成轮次留在本仓库之外。操作人员冻结全部 25 个文件（六类各四个文件，
加共享 `DESIGN.md`）后，从上一级 `android-a2app-card-templates/` 目录执行：

```sh
python3 import-snapshot.py --source-root /path/to/frozen-source \
  --base-case collection --model deepseek --round 11 \
  --turn-dir /path/to/deepseek-11-collection-completion \
  --frozen-source --dry-run
```

MiniMax 使用 `--base-case attempts/minimax-r3 --model minimax`，填写其最终轮数，
按时间顺序重复 `--turn-dir` 提供之后的每轮记录。再后续的导入可以将该模型
已有的后续快照作为基线。只有输入已冻结、保留的修改参数已经检查无私有
数据时，才去掉 `--dry-run`。

导入器沿用成功修改历史，复制源码原字节、核对来源清单并在内存重放后续
编辑。缺失／多余文件、符号链接、重复轮次、来源清单不符、已存在的目标
目录及无法复现的编辑都会拒绝。只保留修改参数及轮次汇总计数／哈希，不
保留推理、助手回复和无关工具输出。私有路径拦截不等于通用秘密检测。
不得通过删改源码参数来制造重放成功；证据不足时记录问题，将快照留在
已完成归档之外。

补丁重放遵循已验证 Android 内核的规则：**从向前游标开始选择首个匹配块**，
包括仅含上下文、用于推进游标的 `@@` 块。重复文本也有确定含义；全局唯一
不是内核约定。[语义来源记录](../pinned-apply-patch-semantics.json)关联源码提交、
交叉构建内核、两份归档 APK 及已安装哈希记录。这是构建证据，不是可复现
构建证明。

只接受精确子集：运行时按忽略行尾空白找到的最早候选，还必须逐字节相同。
若更早候选需要模糊匹配，即使后面存在精确匹配也拒绝；不回溯选后项，不
规范化空白。仅支持单独 `@@` 的 Update File 块、LF 源码和末尾换行；新增／
删除／移动文件、扩展标记及无上下文插入仍不支持。失败调用不参与重放；
该固定内核的补丁校验失败具有原子性。仍要求成功修改的完整参数及最终源码
精确哈希，保留原补丁而不编造替代写入。其他运行时必须先验证自己的工具
约定，才能用此重放支持作者来源结论。

按时间顺序保留中断轮次。若轮次目录含 `operator-interruption.json`，导入器
会核对其工具／最终回复计数与转录一致，并将原字节记录保存到 `turn-evidence/`。
生成记录将该轮标为 `operator_interrupted`；助手最终回复为零，不能描述为
模型已完成回复。操作环境或指导错误与模型质量发现分开记录。

导入状态为 **源码已重放；原生和视觉评审待完成**。作者来源重放证明可从
记录修改复现，不证明绝无未记录干预、真实 bundle 完整性或发布者签名。

## 将测试和评审关联到对应快照

记录结果前，对该次运行实际使用的 `main.splash`、manifest、卡片及数据计算
哈希。将本地开发者准入摘要与源码 SHA-256 分开。后续 manifest 改变时重新
执行准入并记录变化；仅脚本哈希相同，不能证明准入的是同一个 bundle。

每个快照单独保留原始报告、精选 PNG 及对应原生快照，并记录运行时提交／
构建／APK、实际工具哈希、轮次历史、工具调用数和已有计时。原始几何发现
与行为断言分开保留。只提供操作测试不能获得证据分，必须实际观察行为。
导出概览的渲染不证明已发布到 shell，也不证明交互触控目标大小。

两个模型使用同样的五项标准：视觉层级／紧凑度；L0／L1／L2 导航可达；
含键盘流程的逐项可逆状态正确；类别风格统一且离线限制真实；原生及视觉
证据绑定对应源码。组件评分与整屏／展示工具界面评分分开报告。目标为整体
至少 4.5/5 且没有功能阻塞；导入通过或提供测试套件都不等于达到此目标。

本地检查不需要手机或供应商：

```sh
python3 test-import-snapshot.py
python3 validate-model-authorship.py --case-dir collection
```

后续快照导入后，将其相对归档目录传给 `--case-dir`；重复此参数即可独立
检查两个模型的历史。
