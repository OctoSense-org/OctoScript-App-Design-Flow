# Android model authorship

- Follow the repository's root `AGENTS.md`. This directory contains reviewed model-authored prototypes with known
  blockers and their evidence, not an accepted or published template collection.
- The user requires Android DeepSeek or MiniMax to author the actual designs,
  card/app source and revisions. Supervising agents may prepare reference
  inventories, provenance, validation and review feedback; do not substitute
  locally authored designs or code for model output.
- Preserve imported model source bytes and connect them to sanitized tool-call
  evidence and hashes. Return requested source fixes to the phone model.
- Here L0/L1/L2 denote presentation depth. Record language admission separately.
- Keep English/Chinese summaries and review criteria aligned. Pending work stays
  pending until matching native, model and reviewer evidence is available.
- Do not import credentials, provider profiles, personal account data or private
  reasoning. Keep evidence outside any runnable bundle's source directory.
